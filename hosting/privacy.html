Política de privacidad de CineTrack

Versión de trabajo para la aplicación académica CineTrack. Debe revisarse nuevamente antes de la publicación definitiva.

Datos locales

La lista personal, estados de visualización, favoritos, puntuaciones y comentarios privados se almacenan localmente en el dispositivo mediante Room. Las preferencias de apariencia se almacenan mediante DataStore.

Cuenta y datos en Firebase

Firebase Authentication procesa el correo y la identidad necesaria para iniciar sesión. Si el usuario decide crear un perfil público o publicar una reseña, esos datos pueden almacenarse en Cloud Firestore. Una foto de perfil puede almacenarse en Firebase Storage si esa función está habilitada.

Catálogo audiovisual

CineTrack utiliza la API de The Movie Database (TMDB) para consultar películas, series, imágenes, créditos y recomendaciones. CineTrack no envía a TMDB la lista privada del usuario, sus comentarios privados ni sus credenciales de Firebase.

Contenido público

Las reseñas son privadas por defecto. Solo se publican cuando el usuario activa explícitamente la opción correspondiente. Los perfiles públicos pueden mostrar nombre, avatar, género, películas favoritas y reseñas que el usuario haya decidido publicar.

Eliminación

El usuario puede iniciar la eliminación desde Configuración → Eliminar cuenta. También existe un recurso externo en /delete-account. La eliminación intenta borrar el perfil público, reseñas públicas, datos privados locales y la cuenta de autenticación asociada.

Seguridad y terceros

La app usa conexiones HTTPS para TMDB y los servicios de Firebase. CineTrack no incorpora actualmente publicidad ni un SDK de analítica. Esta política debe actualizarse si se incorporan nuevos servicios.
